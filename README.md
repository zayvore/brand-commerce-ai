# Brand Commerce AI

AI-powered multi-role commerce, dropshipping, manufacturing, sourcing, private-label and brand-building platform.

## Product vision

One platform where users can:

- Start a dropshipping business
- Build and manage their own brands
- Discover suppliers and manufacturers
- Request quotations and order samples
- Launch OEM/ODM/private-label products
- Build or connect a custom ecommerce website
- Connect sales channels such as marketplaces through supported APIs
- Manage orders, inventory, fulfillment and analytics
- Use AI for product research, branding, listings, pricing, marketing and launch planning

## Core workspaces

- Brand Owner
- Dropshipper
- Manufacturer
- Supplier
- Sourcing Agent
- Designer
- Quality Inspector
- Logistics Partner
- Warehouse Partner
- Marketing Partner
- Super Admin

## Initial stack

- Next.js + TypeScript
- Tailwind CSS
- Supabase PostgreSQL/Auth/Storage
- Multi-tenant workspace architecture
- Row Level Security
- AI provider abstraction
